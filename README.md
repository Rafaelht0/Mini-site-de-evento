# Mini Site de Evento em HTML

> Exercício prático da disciplina **Desenvolvimento Web em HTML5, CSS, JavaScript e PHP**.

Este projeto é um exercício de estudo, não um site real. O objetivo é praticar HTML puro
(sem CSS e sem JavaScript): estrutura semântica, navegação entre páginas, imagens, listas,
tabelas e formulários.

## Cenário

Site fictício de divulgação do evento **Tech Experience 2026**, com páginas para
apresentação do evento, programação e inscrição.

## Estrutura do projeto

```
meu-evento/
│
├── index.html         Página inicial (apresentação do evento)
├── programacao.html    Programação em tabela
├── inscricao.html      Formulário de inscrição
│
└── imagens/
    └── tecnologia_strade-scaled.jpg
```

## Como visualizar

Basta abrir o arquivo `index.html` diretamente no navegador (não é necessário servidor).

## Observações

- Foco no HTML: sem CSS e sem JavaScript, propositalmente.
- O formulário de inscrição não envia dados a lugar nenhum (não há backend/PHP nesta etapa).
